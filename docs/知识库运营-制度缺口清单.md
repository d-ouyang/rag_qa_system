## A 类：待补的制度缺口

### 缺口 1（P0）各类假期的**薪资/扣薪规则**缺失

- **证据**（qa_trace 真实轮次）：
  - `那病假呢？` 提问 **22 次**，其中 1 次拒答、**9 次判「依据未确认」**
  - `请问，请病假会不会扣除当天工资？` → 依据未确认（2026-10-17 18:18）
  - `我生病了，要请病假，不知道扣不扣工资？` → 依据未确认（2026-10-17 18:53）
  - `我想咨询下事假怎么申请，另外事假期间工资是怎么算的？` → 依据未确认（2026-10-17 22:35）
- **库内现状**：`05_考勤管理制度.md` 第九条表格**只有假别 / 天数标准 / 审批权限 / 所需材料**（事假≤20天、病假凭证明、婚假10天、陪产假10天、丧假3/1天、调休1:1…），**全篇没有任何薪资扣减条款**；检索「病假 工资 扣薪」命中的是考勤打卡条款（812:1）与员工手册摘要（829:1），与薪资无关。
- **这正是 q041 幻觉的根因**：切片相关（重排分 ~0.32 过阈值）→ 不拒答 → 模型用常识编造扣薪规则 → P4-6 依据校验判未通过。
- **建议补齐内容**：
  1. 病假：是否带薪 / 带薪天数 / 超出部分扣薪比例 / 长期病假（医疗期）待遇
  2. 事假：是否计薪 / 扣薪计算口径（日薪 = ?）/ 是否有上限
  3. 婚假、丧假、陪产假、产假、年假、调休：是否带薪、薪资构成
  4. 扣薪计算基数（基本工资 / 全额工资）与最低标准（不低于当地最低工资的 80% 等合规底线）
- **建议形式**：在 `05_考勤管理制度.md` 第四章新增「第X条 假期薪资与扣减标准」（表格化：假别 × 是否带薪 × 扣减口径），比新增独立文档更好（同一主题不分散）。
- **状态**：⬜ 待反馈 HR（2026-10-18 首次提出）

## 给 HR 的补文档需求（可直接发出）

> 主题：考勤假期制度缺少「假期薪资 / 扣薪标准」
>
> 背景：员工在内部问答系统里高频问「病假/事假扣不扣工资」（近两天已出现 20+ 次），现有《考勤管理制度》只规定了假别、天数、审批权限和所需材料，**没有任何薪资扣减条款**，系统无法回答，只能答「未查到」——这类问题恰恰是员工最关心的。
>
> 需要补充（建议作为《考勤管理制度》第四章新增条款，表格化即可）：
> 1. 各假别是否带薪（病假 / 事假 / 年假 / 婚假 / 丧假 / 陪产假 / 产假 / 调休）
> 2. 不带薪或部分带薪假别的**扣减计算口径**（按基本工资还是全额工资、日薪折算方式）
> 3. 病假长期（医疗期）待遇与上限
> 4. 合规底线（扣减后不低于当地最低工资标准）
>
> 形式建议：Markdown 表格（假别 × 是否带薪 × 扣减口径 × 备注），文档给到我这边后入库，问答系统即可正常作答并给出依据。
