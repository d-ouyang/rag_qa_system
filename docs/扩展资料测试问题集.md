## 一、怎么跑

```bash
make verify-kb-extras                 # 跑全部 19 题（默认清 qa 缓存）
make verify-kb-extras ARGS="--id EXT-13"
make verify-kb-extras ARGS="--keep-cache"
```

判定规则：
- 普通题：sources 中出现任一 `expected_doc_ids`，且答案命中至少 `min_hits` 个 `expected_any`；
- 负样本：无 sources，或答案命中拒答话术（未查到/无法回答等）；
- 结果写入 `data/eval/results/kb-extras-<ts>.json`，含每题的 sources、答案、命中词、grounded。

## 三、已知边界

- 问题集依赖本机后端 8000 与本地知识库；`persist=false`，不写会话。
- 默认清 qa 缓存，保证是真实检索；如需复现缓存行为加 `--keep-cache`。
- 答案由 LLM 生成，存在随机性；同一题多次运行结果可能略有差异，失败项建议复跑确认。
- EXT-15 暴露的是「宽表按条件筛选」的生成缺陷，不是切片缺陷；后续可考虑按类别分组切片或对表格筛选题做结构化查询。
