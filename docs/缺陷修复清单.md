### B2 · `core/vector_store.py` FAISS 初始化 —— 元数据写成 set（切 FAISS 必崩）

**原代码**
```python
self._store = FAISS.from_documents(
    [Document(page_content="初始化向量库", metadata={"source", "init"})],   # ← 是 set 不是 dict
    self.embedding_model
)
```

**症状**：`Document.metadata` 要求 dict，传 set 触发 pydantic 校验失败；默认 chroma 模式不触发，一切到 FAISS 就炸。

**修正**
```python
self._store = FAISS.from_documents(
    [Document(page_content="初始化向量库", metadata={"source": "init"})],
    self.embedding_model
)
```

## 逻辑错 · 不报错但结果是错的

### B4 · `core/retriever.py::retrieve` —— 重排后分数匹配错乱

**原代码**
```python
ranked_docs_with_score = [
    (doc, next(score for doc_, score in docs_with_score if doc_ == doc))
    for doc in ranked_docs
]
```

**问题**：用 Document 内容相等匹配，遇到内容相同的片段会串分数；`next()` 找不到时抛 `StopIteration`；整体 O(n²)。

**修正**
```python
score_map = {id(doc): score for doc, score in docs_with_score}
ranked_docs_with_score = [(doc, score_map.get(id(doc), 0.0)) for doc in ranked_docs]
```

### B6 · `.env` 变量名与 Settings 字段不匹配 —— 改了配置不生效

**问题**：`config/settings.py` 的字段叫 `OLLAMA_MODEL_NAME` / `OPENAI_MODEL_NAME` / `SILICONFLOW_MODEL_NAME`，
而原 `.env` 里写的是 `OLLAMA_MODEL` / `OPENAI_MODEL` / `SILICONFLOW_MODEL`。
Pydantic Settings 按**字段名**匹配环境变量，所以 `.env` 里那三行**完全不生效**，一直在用代码默认值。
原项目默认值恰好和 `.env` 写的一样，所以没暴露——你一改模型名就会发现"改了没反应"。

**修正**：`.env` 里统一用 `_NAME` 后缀（本项目的 `.env.example` 已改对）：
```ini
OLLAMA_MODEL_NAME=qwen3.5:9b
SILICONFLOW_MODEL_NAME=Qwen/Qwen2.5-7B-Instruct
OPENAI_MODEL_NAME=gpt-4o-mini
```

> 同理 `PROJECT_VERSION`（.env 里写的是 `VERSION`）也是不生效的，属同类问题，无害。

### B7 · `config/settings.py` —— CORS 白名单不含新前端端口

**原代码**
```python
ALLOWED_ORIGINS : list[str] = ["http://localhost:8501"]
```

**症状**：换成 Vue/React 后（5173 / 3000），浏览器报 `blocked by CORS policy`。

**修正**（两处都要改）
```python
ALLOWED_ORIGINS : list[str] = [
    "http://localhost:5173", "http://localhost:8501", "http://localhost:3000"
]
```
`.env` 里必须用 **JSON 数组**格式（pydantic-settings 按 JSON 解析 list，逗号分隔会解析失败）：
```ini
ALLOWED_ORIGINS=["http://localhost:5173","http://localhost:8501","http://localhost:3000"]
```

## 依赖层面（已在 requirements.txt 中处理，装依赖前必读）

| 陷阱 | 说明 |
|------|------|
| **langchain 不能升 1.x** | 1.x 把 `create_retrieval_chain` / `create_stuff_documents_chain` 移到了 `langchain-classic`，视频代码会 `ImportError`。必须锁 `langchain==0.3.30`。 |
| **pydantic 上限 2.12** | 原 requirements 未锁 pydantic，会装到 2.13.4，而 chromadb 0.5.x 与它不兼容。已锁 `pydantic==2.11.10`。 |
| **chromadb 不能升 1.x** | `langchain_community.vectorstores.Chroma` 在 0.3.x 只适配 0.4~0.5 系。已锁 `chromadb==0.5.23`。 |
| **Python 版本** | 用 3.11（或 3.10）。3.13 上 torch / faiss / chromadb 普遍缺 wheel，会退回源码编译。 |

| 无鉴权 | 接口裸奔 | 至少加一个 API Key 中间件 |
