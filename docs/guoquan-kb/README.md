## 三、与原模板（云帆科技）的主要修正点

原参考文档以"上海云帆信息技术有限公司（云帆科技）"为例，本文库已系统性适配锅圈食品，主要甄别与修正如下：

1. **主体替换**：公司全称、简称、注册地址（上海闵行）、联系人邮箱（hr@zzgqsh.com）、文件编号前缀（YF→GQ）全部替换为锅圈口径。
2. **价值观修正**：原"务实、创新、协作、成长"替换为锅圈真实价值观**"低调、务实、下沉、谦卑、利他"**；愿景改为**"在家吃就锅圈"**。
3. **岗位示例适配**：原"前端开发工程师"等纯技术岗示例，调整为锅圈总部常见岗位（门店运营、供应链、加盟拓展、数字化研发等）。
4. **IT 系统真实化**：IT/账号类文档中的系统清单，依据 gqsh 代码仓库补全为锅圈真实系统：UPMS、GitLab（gitlab.zzgqsh.com）、内部 Wiki（wiki.zzgqsh.com）、锅圈APP/小程序后台、加盟商小程序后台（gqsh-mp-partner）、门店系统（gqsh-shop-*）、商城 CMS（gqsh-mall-cms）、质量/食安系统（gqsh-quality-h5）等。
5. **补充锅圈特色知识**：新增上市、加盟、供应链、食安、数字化等业务知识文档，弥补原模板仅含通用人事行政制度的不足。

## 四、文件编号规则

- 公司知识库：`GQ-KB-年份-序号`
- 人力资源：`GQ-HR-年份-序号`
- 信息技术：`GQ-IT-年份-序号`
- 财务：`GQ-FI-年份-序号`
- 行政：`GQ-AD-年份-序号`

## 五、使用建议

1. 将本目录作为 RAG 系统的文档源导入，按 markdown 切分（建议标题层级 + 表格保留）建立索引；
2. `公司知识库/` 适合对外问答（官网、加盟、上市、产品等），`内部管理制度/` 适合内部员工问答（入职、考勤、报销、IT 账号等）；
3. 内部制度文档含虚构示例数据（姓名、金额、电话），导入前可按需脱敏或替换为真实模板。
