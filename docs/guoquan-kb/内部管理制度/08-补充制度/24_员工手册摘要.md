## 前言

本手册是锅圈食品企业文化与基本管理制度的摘要，旨在帮助新员工快速了解公司、融入团队。详细制度以各专项制度文件为准，本手册与专项制度冲突时，以专项制度及国家法律法规为准。

## 一、公司简介

锅圈食品（上海）股份有限公司（简称"锅圈"）成立于2019年，是中国领先的一站式在家吃饭餐食产品品牌，旗下明星品牌"锅圈食汇"以社区中央厨房为定位，提供火锅、烧烤、生鲜、即烹等多场景家庭餐食解决方案。2023年11月2日，锅圈在港交所主板上市（股票代码 02517.HK）。公司倡导"低调、务实、下沉、谦卑、利他"的价值观，愿景是"在家吃就锅圈"。

## 二、入职与试用期

1. 新员工入职首日办理入职手续，签订劳动合同，领取工牌与办公设备；
2. 试用期一般为3个月（以劳动合同约定为准），试用期内接受岗位培训与考核；
3. 试用期考核通过后办理转正，转正日期以审批结果为准。

## 三、工作时间与考勤

| 项目 | 说明 |
|---|---|
| 工作时间 | 周一至周五 09:00-18:00（午休12:00-13:00）；门店排班岗位按排班表 |
| 打卡方式 | 企业微信 / OA 打卡 |
| 考勤规则 | 详见《考勤管理制度》 |
| 加班 | 须事先审批，可调休或按规定计薪 |

## 四、休假制度

| 假别 | 标准 |
|---|---|
| 法定节假日 | 按国家规定执行 |
| 带薪年假 | 入职满1年5天起，司龄每增1年增1天，上限15天 |
| 病假 | 凭医疗机构证明，按国家规定计薪 |
| 婚假/产假/陪产假/丧假 | 按上海市规定执行 |
| 事假 | 全年累计不超过20天，无薪 |

*请假须在 OA 提交《请假申请单》并经审批。*

## 五、薪酬福利

1. 工资结构：基本工资 + 岗位工资 + 绩效工资 + 补贴，每月15日发放上月工资；
2. 五险一金：按上海市规定缴纳；
3. 补充福利：补充商业保险、年度体检、节日福利、生日福利、员工内购、团建活动；
4. 工资查询详见《工资查询指引》。

## 六、行为规范

1. 廉洁自律：严禁收受供应商、加盟商、客户贿赂及回扣，严禁利用职务便利谋取私利；
2. 保密义务：未经授权不得向外部泄露公司商业秘密、会员信息、加盟商与经营数据；
3. 办公纪律：工作时间不得从事与工作无关的娱乐活动；
4. 安全规范：遵守消防与网络安全规定，离开工位锁屏，妥善保管门禁卡与账号密码。

## 七、奖惩制度（摘要）

| 类别 | 情形 | 处理 |
|---|---|---|
| 奖励 | 突出业绩、供应链/运营创新、重大贡献 | 表扬、奖金、晋升优先 |
| 违纪 | 旷工、迟到早退、违规报销、泄密、贪污 | 警告、记过、降薪、解除劳动合同 |

## 八、员工关怀与沟通

1. 员工可随时与直属上级、HR 沟通工作与生活问题；
2. 建议与投诉渠道：HR 邮箱 hr@zzgqsh.com、匿名意见箱；
3. 公司定期组织员工大会、满意度调研，欢迎建言。
