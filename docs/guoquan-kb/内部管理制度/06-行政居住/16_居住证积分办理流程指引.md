# 居住证积分办理流程指引

文件编号：GQ-AD-2026-004　　|　　版本：V1.0　　|　　生效日期：2026年9月1日

---

## 一、什么是居住证积分

持《上海市居住证》的人员，可依据《上海市居住证积分管理办法》计算积分，达到标准分值（当前 120 分）可享受子女教育、社会保险等相应公共服务。

## 二、积分主要指标（摘要）

| 指标 | 示例 |
|---|---|
| 年龄 | 43周岁以下满分 |
| 学历 | 本科 60 分、本科+学位 90 分、硕士 100 分 |
| 职称/技能 | 中级职称 100 分 |
| 社保缴纳 | 每满1年 3 分（基数高于社平倍数可加更多） |
| 紧缺专业 / 纳税 / 公益 | 酌情加分 |

## 三、办理流程

1. 用人单位（锅圈食品）在"上海市人力资源和社会保障局"官网注册单位积分账户；
2. 员工本人网上填报个人信息并上传材料；
3. 单位审核提交，人才服务中心受理；4. 审核通过打印《积分通知书》。

## 四、公司支持

- 人力资源部负责单位积分账户维护与员工材料初审；
- 提供社保缴纳基数证明、劳动合同等用工佐证。

*（本文件为内部指引示例，积分规则以官方最新办法为准）*
