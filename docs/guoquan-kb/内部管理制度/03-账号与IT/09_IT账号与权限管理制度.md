# IT 账号与权限管理制度

文件编号：GQ-IT-2026-002　　|　　版本：V1.0　　|　　生效日期：2026年9月1日

---

## 第一章 总则

**第一条** 为规范公司各类信息系统账号管理，保障信息系统与数据安全，防止账号滥用与越权访问，依据国家网络安全法律法规及公司实际情况，制定本制度。

**第二条** 本制度适用于公司所有信息系统账号（包括但不限于 OA、企业微信、企业邮箱、UPMS 统一权限平台、GitLab 代码仓库、内部 Wiki、锅圈APP/小程序管理后台、加盟商小程序后台、门店系统、商城 CMS、质量/食安系统、财务系统、VPN、生产服务器等）的申请、开通、使用、变更与注销全生命周期管理。

## 第二章 账号开通

**第三条** 新员工入职账号开通流程：

1. 用人部门在员工入职前2个工作日，在 OA 系统提交《IT 账号开通申请表》；
2. 部门负责人审批后，IT 部在员工入职当日完成账号开通；
3. 员工首次登录须修改初始密码，并设置符合密码策略的强密码；
4. 业务后台权限（如门店、加盟商、供应链系统）须经对应业务负责人二次审批。

**第四条** 账号权限遵循**最小权限原则**：只授予完成岗位工作所必需的最小权限。数据库、生产服务器、财务系统、加盟商与门店数据等高权限账号，须经部门负责人与信息安全负责人双重审批。

## 第三章 密码与安全要求

**第五条** 密码策略：

| 项目 | 要求 |
|---|---|
| 最小长度 | 10位及以上 |
| 复杂度 | 须包含大写字母、小写字母、数字、特殊字符中至少3类 |
| 有效期 | 每90天强制更换 |
| 失败锁定 | 连续5次输错密码锁定账号30分钟 |
| 禁止事项 | 禁止弱密码；禁止多系统共用同一密码；禁止将密码告知他人或张贴于工位 |

## 第四章 权限变更与账号注销

**第六条** 岗位调整、转岗、晋升导致权限需求变化时，应重新提交权限变更申请，IT 部在2个工作日内完成调整；不再需要的权限应及时回收。

**第七条** 员工离职账号注销：

1. 离职审批通过后，HR 通知 IT 部；
2. IT 部于员工离职当日统一注销全部系统账号，收回硬件设备；
3. 涉及门店、加盟商、供应链等业务权限的，由对应业务部门同步回收；
4. 离职员工账号数据按公司数据管理规定保留6个月后清理。

**第八条** 员工应妥善保管个人账号，禁止出借、转让；因个人原因导致账号泄露造成损失的，由员工承担相应责任。

## 第五章 监督与违规处理

**第九条** IT 部定期（每季度）开展账号权限审计，核对在职人员与实际权限匹配性，发现僵尸账号、权限过大等异常及时处理。

**第十条** 违规处理：

| 违规情形 | 处理 |
|---|---|
| 弱密码、密码共享、账号出借 | 警告并责令立即整改 |
| 越权访问、违规导出门店/会员/加盟商数据 | 视情节给予记过至解除劳动合同，涉嫌违法犯罪的移送司法机关 |
