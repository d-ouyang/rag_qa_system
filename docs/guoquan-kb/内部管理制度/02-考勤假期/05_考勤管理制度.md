# 考勤管理制度

文件编号：GQ-HR-2026-005　　|　　版本：V1.0　　|　　生效日期：2026年9月1日

---

## 第一章 总则

**第一条** 为规范公司考勤管理，维护正常工作秩序，保障员工合法权益，根据国家相关法律法规及公司实际情况，制定本制度。

**第二条** 本制度适用于公司全体正式员工、试用期员工及实习生。门店一线员工（排班制）按门店排班与考勤细则执行，劳务派遣、外包人员按合同约定执行。

**第三条** 人力资源部负责考勤制度制定与监督，各部门负责人负责本部门考勤审核，IT部负责考勤系统（OA/企业微信）维护。

## 第二章 工时与考勤方式

**第四条** 总部职能岗位实行标准工时制，工作日为周一至周五。门店运营、仓储物流等排班岗位按批准的排班表执行。

| 项目 | 时间 |
|---|---|
| 上午上班 | 09:00 |
| 午间休息 | 12:00 - 13:00 |
| 下午下班 | 18:00 |
| 每日标准工时 | 8小时 |

**第五条** 因岗位特点经批准实行不定时工作制或综合计算工时制的，按批准文件执行，但须保证员工休息休假权利。

**第六条** 考勤以企业微信 / OA 系统打卡为准，员工每日上下班各打卡一次；外勤、出差等无法打卡的，按流程提交外勤登记或出差申请，视为正常出勤。

## 第三章 迟到、早退与旷工

**第七条** 迟到、早退按以下标准处理：

| 情形 | 处理标准 |
|---|---|
| 迟到/早退 10分钟以内 | 每月累计3次以内不扣薪，第4次起每次扣款50元 |
| 迟到/早退 10-30分钟 | 每次扣款100元 |
| 迟到/早退 30分钟以上-2小时 | 按旷工半天处理 |
| 迟到/早退 2小时以上 | 按旷工1天处理 |
| 因不可抗力迟到 | 凭证明经部门负责人确认后不扣薪 |

**第八条** 旷工处理：

1. 旷工半天扣除当日全部工资；
2. 旷工1天扣除当日工资并处罚款200元；
3. 连续旷工3天或全年累计旷工5天以上，公司有权解除劳动合同且不支付经济补偿。

## 第四章 请假管理

**第九条** 请假类型、天数及审批权限：

| 假别 | 天数/标准 | 审批权限 | 所需材料 |
|---|---|---|---|
| 事假 | 全年累计不超过20天 | 3天内直属上级；3天以上部门负责人+HR | 请假单 |
| 病假 | 凭医疗机构证明 | 同上 | 病假证明、病历 |
| 年假 | 按司龄5-15天 | 直属上级+HR备案 | 请假单 |
| 婚假 | 10天 | 部门负责人 | 结婚证 |
| 产假 | 按上海市规定（158天） | HR+部门负责人 | 医院证明 |
| 陪产假 | 10天 | 部门负责人 | 出生证明 |
| 丧假 | 直系亲属3天，旁系1天 | 部门负责人 | 相关证明 |
| 调休 | 按加班时长1:1 | 直属上级 | 加班审批单 |

**第十条** 请假须提前在 OA 系统提交《请假申请单》，审批通过后方可休假；特殊情况可事后24小时内补办，否则按旷工处理。

## 第五章 加班管理

**第十一条** 加班须事先经直属上级批准并提交《加班审批单》，原则上每日加班不超过3小时，每月累计不超过36小时。

**第十二条** 加班补偿：工作日加班按1:1调休；法定节假日加班支付300%日工资。当月无法调休的工作日加班，经批准可折算150%日工资。

## 第六章 考勤异常处理

**第十三条** 因系统故障、忘打卡等造成考勤异常的，应在3个工作日内提交《考勤异常说明》经直属上级确认，逾期视为旷工。

**第十四条** 严禁代打卡、伪造考勤记录，一经查实按奖惩制度严肃处理。
