# OA 系统常用流程操作指引

文件编号：GQ-AD-2026-002　　|　　版本：V1.0　　|　　生效日期：2026年9月1日

---

## 一、系统入口

- 网页端：公司内网 OA 地址（由 IT 部提供）；
- 移动端：企业微信 → 工作台 → OA 应用；
- 登录：统一使用 UPMS 账号（企业邮箱前缀 + 强密码）。

## 二、常用流程清单

| 流程 | 入口路径 | 审批链 |
|---|---|---|
| 请假申请 | OA → 人事 → 请假申请 | 直属上级 →（3天以上）部门负责人 → HR |
| 加班申请 | OA → 人事 → 加班申请 | 直属上级 → 部门负责人 |
| 费用报销 | OA → 财务 → 费用报销 | 部门负责人 → 财务 →（超权限）分管领导 |
| 用章申请 | OA → 行政 → 用章申请 | 部门负责人 → 法务 → 分管领导 → 行政 |
| IT 账号开通 | OA → IT → 账号开通 | 部门负责人 → IT |
| 出差申请 | OA → 行政 → 出差申请 | 直属上级 → 部门负责人 |
| 培训申请 | OA → 人事 → 培训申请 | 部门负责人 → HR |
| 采购/固定资产领用 | OA → 行政 → 资产领用 | 部门负责人 → 行政 |

## 三、通用操作步骤

1. 进入对应流程，填写表单（带 * 为必填）；
2. 上传附件（发票、证明、合同等）；
3. 选择审批人并提交；
4. 在"我的流程"中查看审批进度；
5. 审批完成后，按流程到对应部门办理（如财务打款、行政盖章）。

## 四、注意事项

- 表单提交前请确认信息准确，提交后如需修改须撤回或由审批人退回；
- 紧急事项可先电话/企业微信沟通，再补 OA 流程；
- 系统异常请联系 IT 部（企业微信搜"IT 服务"）。
