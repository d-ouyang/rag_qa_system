# 锅圈食品 业务与产品

文件编号：GQ-KB-2026-005　　|　　版本：V1.0　　|　　整理日期：2026.03

## 一、业务定位

锅圈食品是**"一站式在家吃饭餐食产品品牌"**，围绕家庭餐桌的多元化用餐场景，提供即食、即热、即煮、即配四类餐食解决方案。区别于传统流通商，锅圈以**餐饮企业的产品能力**为对标，强调"自己能吃、家人能吃"的选品标准。

## 二、八大产品类别

截至2023年4月30日，锅圈产品组合涵盖八大类别、约 710 个 SKU：

| 类别 | 代表产品 |
|---|---|
| 火锅产品 | 底料、蘸料、丸滑、涮肉、火锅菜 |
| 烧烤产品 | 腌肉、串类、烧烤酱料、烤蔬菜 |
| 饮料 | 果汁、茶饮、酒饮 |
| 一人食 | 小份装、单人火锅、速食 |
| 即烹餐包 | 预制菜、调理包、家常小炒 |
| 生鲜食品 | 蔬菜、肉禽、水产 |
| 西餐 | 意面、披萨、牛排等 |
| 零食 | 休闲零嘴、佐餐小吃 |

> 后期品类持续扩容，从火锅、烧烤延伸至中餐小炒、农场源头好物、露营场景、酒饮等，"不是爆品不上架"成为选品原则之一。

## 三、渠道结构

1. **线下社区门店**：加盟为主、自营为辅，深入社区，承担"最后一公里"与"店仓一体"职能。
2. **锅圈APP**：自有线上商城，会员运营与复购核心阵地。
3. **微信小程序**：轻量下单、门店自提/到家履约。
4. **第三方外卖平台**：美团、饿了么等到家服务，扩大即时履约半径。
5. **社区私域**：通过社群、企业微信等沉淀社区熟客关系。

## 四、盈利模式

- **总部盈利**：以供应链差价（商品毛利）为主要盈利来源，而非收取高额销售额分成，以此保障加盟商单店盈利能力（综合毛利率据行业研究约30%—35%）。
- **加盟商盈利**：依托总部整店输出与标准化运营，单店投资回报以"单店盈利模型"为核心考核。
- **区域服务商**：头部加盟商可升级为区域服务商，承担本地化运营支持，并获得新店发展与服务区域供应链分润激励。

## 五、选品与研发

- 自主研发或合作研发 SKU 占比据公开资料约 67%。
- 建立 AI 选品系统，依据区域、门店销售数据与消费者需求智能选品与汰换 SKU，提升商品动销率。
- 上游与**得利斯、安井、三全食品、国联水产**等知名食品企业合作，优选品类头部供应商。
