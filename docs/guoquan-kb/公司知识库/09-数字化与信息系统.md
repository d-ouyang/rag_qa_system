## 一、数字化战略定位

锅圈将数字化视为"万店级运营"的中枢能力，提出**"以AI大模型为脑，用万店数据赋能决策"**。内部系统覆盖消费者端、加盟商端、门店端、供应链端与职能管理端，形成从生产到零售的数字化闭环。

## 二、主要业务系统（基于内部代码仓库梳理）

| 系统 / 仓库 | 定位 | 技术栈（参考） |
|---|---|---|
| **锅圈APP / 微信小程序（gqsh-mp-wx）** | 消费者端：下单、会员、到家履约 | 微信小程序 / 多端 |
| **gq-saas-mall-applet** | SaaS 商城小程序（多租户商城能力） | 小程序 |
| **gq-saas-mall-h5** | SaaS 商城 H5 | H5 |
| **gqsh-mall-cms / gqsh-cms-ui-h5 / gqsh-cms-shared** | 商城 CMS 与组件体系（B端装修、H5组件、公共逻辑） | 微前端 / 组件库 |
| **gqsh-community-h5（锅圈之家）** | 社区内容 / 社群运营 H5 | Vue3 + TS + Vite + Pinia + Vant |
| **gqsh-mp-partner（锅圈加盟小程序）** | 加盟商端：加盟咨询、签约、经营 | uni-app + Vue3 + TS + Vite |
| **gqsh-shop-h5 / gqsh-shop-web** | 门店端：门店经营、店务管理 | H5 / Web |
| **gqsh-quality-h5** | 食安 / 质量管控 H5 | H5 |
| **gqsh-uni-app** | 跨端统一应用基座 | uni-app |
| **gqsh-upms-web（UPMS）** | 用户与权限管理系统（统一身份、菜单、角色） | Web 管理后台 |

## 三、协同与基础设施

- **代码托管**：内部 GitLab（`gitlab.zzgqsh.com`）。
- **知识/接口文档**：内部 Wiki（`wiki.zzgqsh.com`）。
- **统一身份与权限**：UPMS 作为用户、角色、权限、菜单的中央管理，对接各业务后台。
- **多租户能力**：SaaS 商城体系支持多租户/多门店配置，tenantId 区分业务租户。
- **AI 能力**：AI 选品、智能订货、经营诊断等模型逐步嵌入各业务系统。

## 四、典型业务能力（商城侧）

- 商品类型枚举：`单品 / 可选套餐 / 固定套餐`；
- 活动商品类型：`换购品 / 商品卡兑换品 / 抖音团购券兑换 / 拼团 / 砍价 / 接龙` 等；
- 多端一致的商品中心、订单中心、营销中心由 CMS + SaaS 体系统一承载。

## 五、数据安全与治理

- 消费者隐私、会员数据、加盟商经营数据分级管理；
- 系统账号遵循最小权限原则，统一经 UPMS 与 IT 流程开通（详见《IT账号与权限管理制度》）。
