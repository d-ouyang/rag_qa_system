## 一、发展里程碑

| 时间 | 事件 |
|---|---|
| 2017年 | 锅圈食汇首店在河南郑州福元路开业，定位"让老百姓在家也能吃上火锅"。 |
| 2019年7月11日 | 锅圈食品（上海）股份有限公司注册成立，主体落地上海。 |
| 2020年初 | 全国加盟门店约 1,441 家。 |
| 2020—2022年 | 门店快速扩张，三年新增加盟店分别约 4,296 / 6,864 / 9,216 家。 |
| 2022年12月31日 | 全国门店 9,221 家，其中加盟店 9,216 家、自营店 5 家，加盟占比约99.9%。 |
| 2023年4月3日 | 正式向港交所递交招股说明书，华泰国际、中金公司担任联席保荐人。 |
| 2023年10月4日 | 二次递表港交所。 |
| 2023年10月 | 通过港交所上市聆讯。 |
| 2023年11月2日 | 在港交所主板挂牌上市，股票代码 02517.HK，发售价 5.98 港元/股，上市市值约165亿港元。 |
| 2024年6月30日 | 全国门店约 9,660 家加盟门店，覆盖31个省、自治区、直辖市。 |
| 2024年7月22日 | 控股股东上海锅圈实业全资收购河南华鼎冷链仓配科技有限公司，强化冷链仓配能力。 |
| 2024年9月27日 | 公告拟出资 2.46 亿元人民币收购北海逮虾记食品有限公司 41% 股权，延伸虾滑等食材供应链。 |
| 2025年 | 入驻海南儋州工业园，成为园区上市公司之一；全年营业额约 78.1 亿元。 |
| 2026年5月 | 被评为"2026年度ESG社会责任实践领先企业"。 |
| 2026年8月18日 | 中国香港首店 GQ HOMEPOT 于湾仔轩尼诗道开业，开启境外门店探索。 |

## 二、资本与融资脉络

- 招股书披露，锅圈累计完成多轮融资，投资方包括**三全食品、天图投资、茅台建信基金、恒顺醋业、招银国际**等。
- 上市引入基石投资者：**恒顺醋业、欣鑫、锦鼎资本、COFCO Capital Fund（中粮资本）**，合计认购约 3,700.28 万股发售股份。
- 控股股东杨明超及一致行动人（孟先进、李欣华）合计持有已发行股本约 48.64% 权益。

## 三、增长逻辑

锅圈从"一顿火锅"起步，逐步扩展至烧烤、生鲜、即烹餐包、西餐、零食、酒饮等多元场景，提出"继菜场买菜、外卖到家、外出就餐之后的第四种吃饭方案"。其扩张依赖三条主线：

1. **单店盈利模型为骨**：保障加盟商盈利，形成良性开店循环；
2. **产业链效率与总成本领先为魂**：构筑极致质价比护城河；
3. **AI大模型为脑**：用万店数据赋能选品、订货与经营决策。
