# 锅圈食品 品牌与营销

文件编号：GQ-KB-2026-011　　|　　版本：V1.0　　|　　整理日期：2026.03

---

## 一、品牌体系

- **主品牌**：锅圈食汇（GQ SHI HUI），定位"一站式在家吃饭餐食产品品牌"；
- **门店人格**：社区中央厨房、"有温度的中国好邻居"；
- **境外探索**：2026年8月香港首店 GQ HOMEPOT 于湾仔开业，启用新店型探索。

## 二、品牌主张

- **核心口号**："在家吃就锅圈"；"多、快、好、省"；
- **价值主张**：美食平权——让世界美味走进寻常百姓家；
- **场景延展**：从"一顿火锅"到"一个家的日常"，覆盖火锅、烧烤、露营、小炒、农场、酒饮等。

## 三、营销与渠道

| 渠道 | 作用 |
|---|---|
| 线下门店 | 品牌曝光、体验、店仓一体履约 |
| 锅圈APP / 小程序 | 会员沉淀、复购、私域运营 |
| 第三方外卖 | 即时到家，扩大履约半径 |
| 社交商务平台 | 内容种草、社群裂变 |
| 户外 / 区域媒体 | 本地心智占领 |
| 总部品牌宣传 | 网络主流交互平台 + 区域投放 |

## 四、会员运营

- 截至2023年4月30日注册会员约 2,240 万；
- 依托 CRM 收集分析消费者数据，精准洞察需求，驱动复购与选品；
- 会员权益、积分、社群活动构成私域增长闭环。

## 五、营销节奏

- 围绕火锅季、烧烤季、节假日、露营季等场景化营销；
- 通过促销活动策划、门店形象设计、线上话题联动提升转化；
- 区域服务商与门店协同落地本地化营销。
