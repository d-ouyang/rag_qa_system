## 3. 决策与代价

- **管理端生产形态 = 静态产物 + Caddy file_server**（与个人站同模式，零新容器）：
  否掉「塞进 rag-frontend 镜像」（污染）与「常驻 dev server」（5174 裸跑无生产
  加固）。API 走同域 `/api*` 反代网关——admin-console 的 API client 本就是
  相对路径，零代码适配。
- **admin-console 纳入 CI/CD**：deploy.sh `[7/7]` 用一次性 `node:22-alpine`
  容器构建（宿主机无 node；npm cache 挂 `admin_npm_cache` volume 提速），
  rsync 到 `/var/www/admin`；**构建失败只报错不阻断服务部署**（静态站点挂了
  不该连累后端）。
- **安全收口 = `BIND_ADDR=127.0.0.1` + 删防火墙 8080 规则**：compose 本就支持
  `BIND_ADDR` 变量（p1.5b 埋的伏笔），收口只需一行 env + 重建 + 控制台删规则。
  Caddy（宿主机 80/443）成为唯一公网入口。

## 4. 坑实录

### 4.1 🔴 手动 sudo 运维脚本弄挂整条 CI/CD（当天全部 push 静默未部署）

**现象**：备案号 push 后 qa 页面无变化；前端版本号停在 p2.23。

**定位**：不是「等一等」，而是用 GitHub Actions API 查 runs——
**当天所有 Deploy run 全部 `failure`**；再看 job log，死在 `git clean -fd`：
`coscli_output/.../error.report: Permission denied`。

**根因链**：手动 `sudo bash backup_to_cos.sh` → coscli 把失败日志写在
**当前工作目录**（`/opt/qa/coscli_output/`，root 属主）→ 部署脚本（ubuntu）
`git clean -fd` 删不掉 → exit 1 → 整链失败。**root 的文件挡住了整个自动部署，
且没有任何人主动看 Actions 页就不会被发现。**

**双修**：`.gitignore` 忽略 `coscli_output/`（git clean 不碰被忽略的）+
脚本 `--log-path /var/log/qa-backup/`（日志与仓库彻底脱钩）。

**教训入档**：
1. **手动 `sudo` 跑任何工作目录在仓库内的脚本，都可能往仓库里落 root 文件**；
2. **「push 之后」必须主动确认部署结果**——见 §6；
3. 失败要显眼：git clean 失败在 runner 日志里只是 warning + exit 1，不盯就看不见。

### 4.2 Caddyfile 远程编辑三连败 → heredoc 覆盖定标

三次尝试经 SSH 粘贴都丢空格/变形（`try_files {path}/index.html` 缺空格、
sed 多行替换被吃）。`validate` 每次都能抓到（好样的），最终方案固定为
**`sudo tee` + heredoc 整段覆盖**：粘贴目标只有一块，heredoc 原样落盘。
**结论：远程改配置文件，永不 sed，只整段覆盖。**

### 4.3 admin-console 建页漏 `.head`

「每页 scoped 各写一份 `.head`/`.filters`」的模式让 UsageView 建页时漏抄——
el-select 裸放块级容器默认宽 100%，表现为筛选框独占整行。补齐样式并对齐
UsersView 参数（`160px + margin-bottom 16px`）。
**模式脆弱性记录在案**：新页面的 checklist 必须含「`.head` / `.filters` 样式抄齐」。

## 6. 附：如何确认「push 之后部署成功」

三看（快 → 全）：

1. **看服务结果**（服务器，最快）：
   ```bash
   cd /opt/qa && git log --oneline -1        # 应等于你刚 push 的 commit
   curl -s http://127.0.0.1:8080/api/health  # 应 ok
   ```
2. **看 Actions 状态**（网页）：仓库 → Actions tab → 最新 run 绿勾即成功、
   红叉点进去看失败步骤日志。
3. **命令行查**（Mac，装过 gh 的话）：
   ```bash
   gh run list -R d-ouyang/rag_qa_system --limit 3
   ```
