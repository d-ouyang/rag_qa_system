# v4.1.0-p4.2e · 问答缓存长度门控 6→4（2026-11-17）

## 线上实测

「年假的规定」在不同会话反复提问，从不命中缓存。根因：`is_standalone_question`
长度门控 `len < 6` 拒写——这句正好 **5 个字**。lookup 无门控、写入有门控，
池子里永远没有这条 → 永远 miss。

## 修复

门控 6→4：拦「你好/在吗」寒暄，放行「年假的规定」这类完整短名词问句；
指代正则（它/这个/继续…）不变。改写与缓存 key 无关：存储/查找都用
**用户原问题**（normalize 后 sha256），改写结果只进 standalone_question 字段。

   每问多一次 embedding 调用，命中省 ~3000 tokens。独立迭代评估。
