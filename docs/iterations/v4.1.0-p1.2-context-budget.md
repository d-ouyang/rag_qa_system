## 设计拍板

1. **整块丢弃而非逐字截断**：模型对着半句话会编；只有「第一块就超预算」才截断
   该块（保底给到 top1 资料）并加「…（超长截断）」标记。
2. **flag 而非 settings 常量**：与 qa_direct_hit / query_rewrite 同机制，管理端
   热调（如某文档切片异常长时临时放宽）。
3. **接入点只收 format_docs / _format_candidate_docs 两处**：它们是检索结果进
   prompt 的唯二出口（qa_direct 命中不检索不走此路）。
