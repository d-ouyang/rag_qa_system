# v4.1.0-p4.2f · 管理端溯源页四项体验修复（2026-11-17）

## 修复项（用户验收反馈）

1. **会话 id 点击复制**：列表展示不全（截断 10 字符），单元格改为点击复制完整值
   （clipboard API + execCommand 兜底 + toast 反馈）。
2. **流程图 SVG 下载**：实走路径标题行加「下载流程图 SVG」——XMLSerializer 序列化
   当前 svg 节点、补 xmlns 后以 `trace-{id}-flow.svg` 落盘。
3. **候选清单**：按钮「原文」改「切片内容」；新增「预览原文档」——chunk_id 前缀
   即 doc_id（契约 `<doc_id>:<index>`），带 admin token 走 `/api/v1/documents/download`
   取 blob（admin http.ts 补 getFile，RFC 5987 文件名解析与主前端同款）；
   文本类（md/txt/csv/log/json/yaml）在弹窗直接展示，二进制（pdf 等）新开标签页
   交给浏览器。权限走既有 kb ACL（superadmin 可读全库）+ doc_download_enabled 开关。
4. **切片展开区配色**：admin 是暗色主题（--text-1=#e6eaf2），`.chunk-cell` 却硬编码
   浅底 #f8fafc → 亮字亮底看不清（线上截图实测）。展开区改 `var(--bg-elevated)`，
   文字用主题变量，弹窗 `.doc-pre` 同口径。
