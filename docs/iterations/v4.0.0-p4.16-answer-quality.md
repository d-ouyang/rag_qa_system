> 来源：`docs/验收-生产能力演示-2026-11-05.md` 用生产账号跑 12 用例，事实准确 10/12，
> 暴露的三类问题（P0 反向编造、P1 拒答话术混排、P2 多源重复）。本版逐条修，**本地验证通过，未上线**。

## 1. P0 反向编造（最严重：给出与原文相反的结论）

### 现象

```
问：怎么请事假？事假扣不扣钱？
答：… 事假不扣发工资 … 资料中未明确说明…可以推断…可能不发放
```

而 `24_员工手册摘要.md` 原文是「事假：全年累计不超过20天，**无薪**」。

### 根因（查了三层，前两层都不是）

1. **不是"没召回"**：`829:1` 这片里表格完整写着「| 事假 | …，无薪 |」，
   但用「事假扣不扣钱」检索时它只有 **0.0055** 分，被阈值 0.1 挡在门外。
2. **不是"召回不到就编"**：补了极性问句的第二路检索后（见下），829:1 进了上下文，
   模型**仍然**说「资料未规定事假工资」——因为另一份《考勤管理制度》的请假表只写了天数和审批权限、
   没提工资，模型见两份详略不同，选了「说不清」。
3. **真根因是"多源详略不同时的覆盖判定"**：模型没有「以更具体那条为准」的概念，
   对缺失的那份更敏感，于是把"某份没写"读成"资料没规定"。

### 修法（三处协同）

| 位置 | 改动 |
|---|---|
| 检索 | 新增 `_polar_secondary_query()`：识别「扣不扣 / 能不能报 / 要不要 / 有没有」这类**是非问句**，把口语极性词剥掉、补回被省略的宾语（`事假扣不扣钱` → `事假 工资 规定`），再检索一路与主路用 `_merge_retrieval` 合并。实测同一查询：`事假扣不扣钱` 召回不到员工手册，`事假 工资` 直接把它排到 top1（0.329）。`prepared["polar_used"]` 记录是否走了这一路 |
| 生成 | 规则 11：是非问句只依据资料直接表述，**禁止反向结论**（资料没写「不扣」≠「不扣」）；规则 13：多份资料详略不同时**以更具体的为准**，不得因另一份没写就判「资料未规定」，并给出本案例作为示例 |
| 判官 | 反向结论也是实质论断：资料写「无薪」而答案写「不扣发工资」即 unsupported |

### 验证

```
问：事假有工资吗？            → 资料中提到事假全年累计不超过20天，无薪。
问：怎么请事假？事假扣不扣钱？  → 请假须提前在 OA 提交《请假申请单》… 事假全年累计不超过20天，无薪。
```

## 2. P1 拒答话术混排（"免责声明"式前缀）

### 现象

```
根据现有制度未查到相关规定。资料中提到，迟到/早退10分钟以内，每月累计3次以内不扣薪，第4次起每次扣款50元。
```

p4.15e 用「规则互斥 + 反例 few-shot」压下去过，换个问法又回来 —— **纯提示词是概率性的**，不能作为唯一手段。

### 修法：换成确定性过滤 `_RefusalSentenceFilter`

- 逐句扫描，识别「整句就是那句声明」（允许前面带「因此，」「所以，」）；
- 若答案**别处已有实质内容** → 丢掉这句（句中的则删除该句本身并清理残留标点）；
- 若**整条答案只有这句**（真·无关问题）→ 原样保留，不破坏拒答语义；
- 流式按句缓冲：先扣住这句、看到后续实质内容再决定发不发，**用户看到的与落库的一致**（不会"发出去再撤回"）。
- 同步链路用同一份规则（`_strip_refusal_prefix`），保证 `query()` 与流式口径一致。

### 副作用与配套

- 负样本 EXT-19 的答案从「根据现有制度未查到相关规定。资料中…」变成「资料中提到…但未涉及2027年的营收目标。」
  ——**语义仍是拒答**，但断言 `hits=['未查到']` 会失败，说明原来的判据是"词表匹配"而非"语义"。
- 因此把 `verify_kb_extras.py` 的负样本判定改成**语义式**：`否词（未/没有/暂无/不包含）+ 短距离内告知类动词
  （提及/涉及/提供/给出/包含/查到/规定/说明/列明/相关/数据/信息）`，同时保留 `expected_any` 兜底。
  实测四轮里模型分别用了「未提及」「未涉及」「没有关于」，追同义词是追不完的。

## 3. P2 多源重复（同一张表被 5 片重复召回）

### 现象

「开业验收包含哪些模块」把「证照」列了三遍，361 字里有效信息约 150 字。

### 修法（只用提示词，且刻意保守）

规则 12：「多个资料片段重复同一内容时，合并成一条即可，不要逐片罗列。」

### 结果：**未解决，且中间版本更糟**

- 第一版写成「同一事实只陈述一次…两个条目名称相同/包含时只保留信息更全的」→ 模型开始**穷举**：
  9 条变 20 条，还加了「消防：未单独列出，但包含在安全卫生模块中」这类废话。
- 收敛成最小表述后回到 9 条左右，但「证照」仍出现 3 次。

**结论**：这条本质是「同一张表被多片重叠召回」+「模型穷举倾向」，不是措辞问题。
下一步应该做**确定性去重**（列表项相似度合并）或**来源去重**（召回时合并高度重叠的片段），本轮不做，先记录。

## 7. 追加：判官被「拒答句」污染（2026-11-06 诊断 demo-c02 红框）

用户问：会话 `demo-c02-1105`（问「迟到多少次开始扣薪？」）的引用资料里明明写着答案，
为什么还挂「依据校验：请勿采信」，而且 `unsupported` 是**问题本身**？

### 对照实验（把变量控制到只剩一句话）

同一问题、同一上下文（`812:1` 一片），只改答案：

| 答案 | 判官结果 |
|---|---|
| `资料中提到，迟到/早退10分钟以内，每月累计3次以内不扣薪，第4次起每次扣款50元。` | `grounded=True`，`unsupported=[]` |
| 上面这句**前面加上**`根据现有制度未查到相关规定。` | `grounded=False`，`unsupported=[「迟到/早退10分钟以内…每次扣款50元」]` |

**结论：那句「未查到」会把判官带偏** —— 它看到答案自称"没查到"，就把后面本来有依据的数字判成编造
（第二次实测更狠：直接把资料里明写的那句话列为 unsupported）。

### 这解释了线上那次

p4.15e 时答案带前缀，判官判 False；那一次模型把**问题**填进 `unsupported`，这一次把**答案正文**填进去
—— 表现不同，根因同一个：**判官被答案自己的免责声明污染**。
p4.15e 加的「问题本身不得列入」只治了其中一种表现，没治病根。

### 两处补救（本版新增）

1. **上游**：p4.16 的 `_RefusalSentenceFilter` 让那句话根本到不了判官（实测同问题 `grounded=True`）；
2. **下游**：判官提示词加一条——「答案里出现『根据现有制度未查到相关规定』时，**不能**据此判定其余论断
   无依据，必须逐条回上下文核对」。

复测旧答案（带前缀）：`grounded=False` 但 `unsupported=['根据现有制度未查到相关规定']`
—— 从"冤枉正确内容"变成"准确指出那句错误声明"，方向对了。

## 8. 追加：QA 直击来源「无法预览」（前端，98e765a）

线上现象：doc_id=49 点「预览原文档」只显示「该格式暂不支持在线预览，请点右上角下载」，
而接口返回的是 markdown（4104 字节，开头 `# 考勤管理制度`），`Content-Disposition` 里也是
`filename*=utf-8''05_考勤管理制度.md`。

根因：`DocumentPreview.vue` 用**展示名**推扩展名。
- 这条来源是 QA 直击，`_qa_hit_sources` 把 `file_name` 设成 `entry.source_doc`（文档标题「考勤管理制度」），**没有扩展名**；
- 于是 `ext` 为空 → `kindLabel` 落到「文件」→ 走「不支持预览」分支；
- 而 `getFile()` 明明已从响应头解析出 `05_考勤管理制度.md`，组件只把它当兜底、没用于判类型。

修法：展示名与判类型**分成两个字段**——展示仍用标题（对用户更友好），
判类型优先用下载响应里的真实文件名，再退到 blob MIME（`application/pdf` / `image/*` / `text/*` / markdown）。
影响面：所有「名字没有扩展名」的来源（QA 直击、历史改过名的数据）都能正常预览。

`vue-tsc` + `vite build` 通过。
