## 三、必须暴露的问题（按严重度）

### ❌ c10 事实错误：给了一条与库内另一份文件相反的规定

```
问：怎么请事假？事假扣不扣钱？
答：… ### 扣款规则
    - 全年累计不超过20天。
    - 事假不扣发工资，但超过3天的部分需按审批权限逐级审批。
    资料中未明确说明事假期间是否发放工资，但根据请假流程…因此可以推断事假期间工资可能不发放，
    但具体是否扣款需根据审批结果确定。
```

两处硬伤：

1. **「事假不扣发工资」与原文相反**。`24_员工手册摘要.md` 写的是「事假 | 全年累计不超过20天，**无薪**」。
   而这次命中的 4 条来源是 `06_请假申请单.md` 和 `考勤制度`（表格只写天数与审批权限，**没有工资口径**）——
   员工手册那一片**没被召回**，模型就在缺口处自己补了结论。
2. **同一段里自相矛盾**：先说「不扣发工资」，接着又说「可能不发放…需根据审批结果确定」。

依据校验只标了「事假期间是否发放工资未明确说明」未支撑，**没抓出反向断言本身**。
→ 这类「极性问句（扣不扣/能不能/要不要）+ 跨文档」是最危险的组合：答案里给了一个**确定的反向结论**，
而且引用看起来合理。

### ⚠️ c02 / c08 拒答话术与数据混排（p4.15e 的修复只是降低了概率，没根治）

```
c02 → 根据现有制度未查到相关规定。资料中提到，迟到/早退10分钟以内，每月累计3次以内不扣薪，第4次起每次扣款50元。
c08 → 根据现有制度未查到相关规定。资料中提到讲师课酬的总预算为 180000 元，但没有按讲师拆分的明细。
```
数字都是对的，但那句「未查到」是**免责声明式的前缀**，用户第一眼看到的是"没有相关规定"。
p4.15e 用「规则互斥 + 反例 few-shot」把它压下去过（同一问题当时改对了），换个问法又回来了——
说明**纯提示词约束是概率性的**。

## 四、结论与建议

**能力面**：四类文档解析、混合检索+重排、QA 直击、多轮指代、复合分解、拒答、依据校验、引用溯源，
在生产上**都能真实跑通**，延迟 0.2–10.7s（QA 直击与缓存命中在亚秒级）。

**质量面**达不到"可以拿去对外演示"的水准，三条改进建议（按性价比排序）：

| 优先级 | 问题 | 建议做法 |
|---|---|---|
| P0 | c10 反向编造 | ① 提示词加「极性问句必须在资料中找**直接表述**，找不到就说未规定，禁止给反向结论」；② judge 增加反向断言检测（答案说"不扣"而资料写"无薪"→ 直接判未支撑）；③ 检索侧对「扣不扣/能不能」类问题做**同主题跨文档补召回**（本次漏了员工手册那片） |
| P1 | c02/c08 拒答前缀 | 不做提示词调优了，改**确定性后处理**：答案若同时含「未查到相关规定」与≥1 个数据行/数字，删掉那句独立成句的前缀（文本手术可控、可测） |
| P2 | c06 重复 | 提示词加「同一事实只陈述一次」；或按句去重（同段落相似度 >0.9 只留一条） |

P0 是唯一"答案错了"的问题，建议优先做。
